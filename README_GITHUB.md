# Prototipo digital Dicapri

Interfaz demostrativa del modelo híbrido para monitoreo de máquinas tejedoras,
predicción de riesgo e inspección de medias.

## Publicación

El frontend se publica automáticamente en GitHub Pages después de cada cambio
en la rama `main`.

Dirección prevista:

https://Zineasta2026.github.io/prototipo-dicapri/

## Alcance público

Esta edición contiene el frontend, los datos reconstruidos para la simulación,
el banco 3D, AMEF, trazabilidad y el modo de criticidad. No contiene fotografías
privadas, pesos YOLO, modelos entrenados ni el backend FastAPI.

GitHub Pages muestra la simulación, pero la inferencia real de YOLO y Random
Forest requiere conectar un backend Python externo.
